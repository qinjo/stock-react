# 0002 — 提示词工程与输出契约

- **状态**：已采纳
- **日期**：2026-09-21
- **相关**：规格 issue #1、工单 T4(#5)/T5(#6)、调研笔记 `_research/提示词优化调研笔记.md`（8 个项目源码级）

## 背景

T4/T5 上线后，真实分析虽能跑通，但质量不达预期，四个可复现的症状：

1. **基本面一节空泛**——只有两三句加一句"数据不足即免责"
2. **目标价 100% 留空**——连续三只股票（茅台/宁德/招行）都是 `price_target: null`，理由是"缺乏盈利数据"
3. **置信度中庸**——62/72/78 之类，缺少区分度
4. **结论套话**——`conclusion` 段产出"综上所述"式复述

根因诊断（均有源码依据，非主观判断）：

| 症状 | 根因 |
|---|---|
| 空泛 | 提示词把 fundamentals 规定为 **"2-4 句"**——容量是我们自己写死的（FinRobot 同类段落要求 800–1000 词） |
| 目标价永空 | `price_target` 是孤立可选槽位、**没有推导路径要求** → null 是零代价默认答案（dexter 用三情景表逼出估值） |
| 中庸 | 置信度用主观词锚定（"证据充分"）→ 必然落中档；TradingAgents 把它定义为**输入属性**（数据点少于 5 个即 low） |
| 套话 | 顶层已有 rating，再要求写 conclusion 只会重复（dexter：memo 不需要结论段，以监控 KPI 收尾） |

## 决策

### 1. 置信度改为**可数锚定**

由代码统计 12 项指标的多空方向（`derived.ts` 的 `tallySignals`），算出一致性比例并映射为置信度**上限**，写入提示词且要求模型"不得超过"：

| 一致性 | 上限 |
|---|---|
| ≥0.9 | 90 |
| ≥0.75 | 80 |
| ≥0.6 | 65 |
| ≥0.5 | 50 |
| <0.5 | 45 |

依据 A_Share_investment_Agent `src/agents/technicals.py:134-136`（`confidence = max(bullish, bearish)/total`）。**这是治"永远 60-70 分"最彻底的办法，且零 LLM 成本。**

### 2. 目标价**双轨制**

- 有数据支撑 → 必须给出 `price_target` **并写明推导路径**（`price_target_basis`）
- 无数据支撑 → 允许为 null，但**必须说明缺什么数据**，禁止无依据的数字

并新增 `invalidation`（判断失效位）：从「区间低点 / SMA50 / SMA200 / 价−2ATR」中选最贴近当前价者，说明依据并给出距离百分比。这让结论**可执行**，而不只是一个方向判断。

### 3. 删除 `conclusion`，改为三块收尾

`sections` 收敛为四节（快照/基本面/技术面/风险），收尾改为：

- `data_limits[]`——数据边界（缺失维度及其对结论的限制）
- `what_would_change_my_mind`——证伪条件
- `monitoring[]`——需持续跟踪的指标与阈值

依据 dexter `memo-style.md:80-88`。

### 4. 基本面槽位**扩容并给出追问模板**

字数下限 300 字，按 WHY（为什么是这个估值）→ WHAT（隐含量说明什么）→ HOW（与趋势是否冲突）→ SO WHAT（对决策意味着什么）展开。依据 FinRobot `major_takeaways_agent.py:8-20`。

### 5. 加**具名谬误清单 + 输出前自检**

谬误清单（线性外推 / 忽略基数 / 相关当因果 / 选择性用数 / 把低估值等同于上涨）来自 A_Share `prompts/debate_room/system.md:26-31`；输出前 7 条自检来自 dexter `SKILL.md:142-153`——**同一次调用内完成，不额外计费**。

### 6. 删掉 `hold` 的"看不清"逃生舱

`hold` 必须举证"多空论据势均力敌且各自成立"；"数据不足"用 `data_limits` 表达，不得伪装成中性结论。

### 7. 数据边界**动态生成**

由代码按实际提供的数据渲染"已提供/未提供"两段，而不是写死一份清单——否则会出现"声明缺失了其实已有的数据"（本轮曾真实发生：模型反复说"未提供历史估值分位"，而该数据后来已接入）。

### 8. 提示词**契约测试**

`test/analysis-parse.test.ts` 断言 system prompt 必含：点时间约束、禁止编造、数据边界段、自检清单、具名谬误、字数下限、置信度上限约束、schema 全部字段名（且不得含已删除的 `conclusion`）。依据 ai-hedge-fund `test_llm_agents.py:212-222`。防止后续改动悄悄丢掉关键约束。

## 后果

**收益**（同票茅台，改造前后对比）

| 指标 | 改造前 | 改造后 |
|---|---|---|
| fundamentals 篇幅 | ~200 字空泛 | 822–900 字，四段递进 |
| 目标价 | null（无理由） | 有锚定值 + 推导路径，或**专业拒绝**（说明缺什么） |
| 失效位/证伪条件/监控指标 | 无 | 齐全，且带可观察阈值 |
| 推理质量 | "便宜但走弱" | 引用财报趋势、估值分位、同业对比做交叉论证 |
| 置信度 | 主观 62 | 78，**严格遵守代码算出的上限 80** |

**代价**

- token：约 3300 → **7000+**（提示词变长 + 输出从 600 增至 2200+ tokens）
- 延迟：3.7s → **12–14s**
- 可通过下调 fundamentals 字数下限与 `monitoring` 条数回调（约省 1/3 输出）

**未采纳**

- **多轮调用**（draft → 空头批判 → 裁决）：调研认为可捕获 TradingAgents 辩论约 70% 价值，但成本 ×3；本轮先榨干单次调用的潜力。
- **为修"留空"而授权模型估算**：A_Share 有一条提示词写着"若缺少精确数值，请根据报道做出合理估计"——这是**明确授权编造**，本项目明确拒绝。宁可诚实地留空并说明缺什么。

**一个待观察点**：置信度上限映射（一致性 → 上限）目前是保守取值，若实际使用中感觉压制过强，可放宽阈值——但这属于调参，不改结构。
