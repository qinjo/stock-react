# 0006 — 前端布局：左侧导航 + 顶栏 + 面板卡片（浅色主题，布局参考 Vibe-Research）

- **状态**：已采纳
- **日期**：2026-11-11
- **相关**：参考项目 [Vibe-Research](https://github.com/simonlin1212/Vibe-Research)（工作台界面结构）；[`README.md` 界面布局](../../README.md#界面布局)；共享面板容器 `frontend/src/components/ui/Panel.tsx`

## 背景

原界面是「顶部一行标题 + 三个模式 tab + 大平铺内容」：单票分析宽屏两栏，筛选器与回测各自把参数和结果堆在一起。工具本身已经从一个搜索框长成了三个栏目（单票分析 / 短线筛选器 / 策略回测），但界面没有随之长出「栏目」概念——三个 tab 的语义只在标题下面的说明文字里，用户切换时缺少稳定的方位感；同类信息（标题、操作按钮、结果）散落在不同层级的自绘边框里，视觉节奏不一致。

用户提出：**页面布局参考 Vibe-Research**（本仓库之外的独立参考项目，其工作台是「左侧栏目导航 + 顶部面包屑 + 卡片化面板」）。

## 决策

### 1. 只借布局结构，不搬视觉主题

只采用参考项目的工作台结构：**左侧栏目导航 → 顶部面包屑栏 → 灰底内容区 → 白底卡片面板**。

不搬它的深色主题、橙色品牌主色与 Google Fonts 字体。理由：

- 本工具是本地运行的免费数据研究工具，浅色 slate 风格已经与现有图表、红涨绿跌的 A 股配色共存，换深色主题会把「表格/图表配色、涨跌语义、告警态」全部重做一遍，收益与风险不成比例；
- 应用要求离线可用，不引入外部字体加载；
- 本次诉求是**布局**，不是品牌改版。

### 2. 外壳：一份导航 DOM，不引入路由

- 左侧栏在宽屏固定 240px，窄屏（`<lg`）折叠成顶部横向导航栏；**品牌 + 导航 + 数据说明只渲染一份 DOM**，靠响应式类切换形态。不采用「宽屏一套 + 窄屏一套」的写法——两套按钮会产生重复的可访问名，测试与读屏都会先炸。
- 顶部栏承担面包屑（工作空间 / 当前栏目）+ 后端连通状态 + 「分析未就绪」提示；连通状态只在这里出现一次（原页脚的状态行一并收敛，避免同一句话在页面上出现两次）。
- 仍然**不引入路由**（沿用「顶部 tab 即模式」的既有决策）：栏目切换是组件状态，不是 URL。

### 3. 面板：一个共享容器 `Panel`

新增 `frontend/src/components/ui/Panel.tsx`，统一「白底卡片 + 细边框 + 轻阴影 + 标题栏（标题 / 补充信息 / 右侧操作）」。各业务面板只声明标题与内容：

- 标题栏固定为「标题 + meta（数据截至 / 样本量）+ actions（主按钮）」三件套，参数区与结果区因此有了同一种开栏节奏；
- 组件内不再自绘 `border + shadow`（原来是各写各的 `rounded-lg border-slate-200 bg-white p-4 shadow-sm`）；
- 只做视觉容器，不承担数据逻辑，组件测试仍按文本/角色断言，不依赖布局类名。

### 4. 单票分析：单列全宽，一块信息一行

选股成功后自上而下依次堆叠：**行情快照 → 日 K 走势 → 技术指标 → 基本面与估值 → AI 分析**，每一块占满整行，**不做左右分栏**。

这样改的原因（用户决策，参考 Vibe-Research 的 K 线区）：K 线要「一行显示全」，图表和长报告都不再被栏宽压缩；此前两栏布局里，行情快照 + 图表 + 指标在 900px 高的笔记本视口装不下，日 K 会被 flex 压到最小高度、底部日期轴被裁。单列后图表拿到整行宽度与固定高度（窄屏 22rem、宽屏 26rem），指标面板也从三组挤压改为可呼吸的三列。

首屏空状态补一张「使用路径」三步卡片，避免第一次打开只有一张搜索框。

### 5. 筛选器与回测：参数面板化

参数区收进一张面板，主按钮放标题栏右侧；模式 / 严格度 / 股票池用 fieldset 分组，结果按面板切块（漏斗摘要、候选卡、回测统计、分组表）。表格统一 `overflow-x-auto` + 表头 `text-slate-400` + 数字列右对齐等宽。

## 后果

- README 的「界面布局」一节同步改写；布局决策记录在本 ADR。
- 前端 133 项测试与 `tsc --noEmit`、`vite build` 保持全绿：改造只动结构与样式，所有中文文案、`aria-label`、`role`、`data-testid` 与红涨绿跌语义未改（`test-setup.ts` 的 klinecharts stub 补了 `setStyles`，与真实 API 对齐）。
- K 线图改用 A 股配色（**红涨绿跌**）：klinecharts 默认是欧美习惯的绿涨红跌，与快照卡、指标面板红色表示上涨的约定相反，`setStyles` 一并修正蜡烛、影线、成交量柱与图例颜色。
- 回归中发现并顺手修掉一个**旧问题**：`KlineChart` 此前只在 `window.resize` 时重算画布，弹性高度变化（侧栏折叠、面板内布局）不触发，底部日期轴会被裁；现在补了 `ResizeObserver`。
- 已用 Chrome headless + 注入 mock 数据截图核对 1440px 与 390px 两种视口下的四个栏目，覆盖空状态、载入态、筛选结果、回测参数页与搜索补全浮层。
