1. **语义翻译是否合理**（最重要的一条）：下面这些"书里的定性描述 → 我们定的数字"，
   你认可吗？不认可的话告诉我该往哪边调。
   - 「刚刚突破 MA100」（L545）→ **10 个交易日**内算"刚突破"，且只影响同档内排序、不筛除
   - 「大幅快速回调」（L1477）→ 回撤 **≥15%**、窗口 **30 日**
   - 「很大的向上跳空」（L1296）→ 宽度 **≥1.0 × ATR20**
   - 「短期内回补」（L1316）→ 缺口失效窗口 **3 日**
   - 「震荡走势」（L627）→ 带宽 **≤20%** 且净位移 ≤ 带宽的一半
   - 「流通市值过大」（L1686，书中只有 51 亿被剔除、17/23 亿保留这一个案例）→ 标准档上限 **80 亿**
2. **止损位是否有依据**：止损是否落在结构低点 / 均线 / 固定比例三者之一，
   空间是否在本档上限之内（宽松 10% / 标准 8% / 严格 5%）。
3. **排除项是否被正确应用**：有没有明显该被剔除的票（ST、停牌、高位涨停、连板）混了进来；
   反过来，有没有该出现却被挡掉的形态。
4. **档序是否符合直觉**：涨停+低位123 是否排在缺口之前；
   同档内止损空间小的是否排在前面。
5. **有没有「看起来就不像那本书挑的票」**——引文、阈值、契约、缓存、数据都已核过，
   所以如果还是觉得某只票不对劲，那问题多半就出在第 1 条的语义翻译上。请指出是哪一只、哪里不对。
